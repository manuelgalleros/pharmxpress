# PharmXpress

PharmXpress is a Point of Sale (POS) system with an integrated Inventory Management System specifically designed for pharmacies. Built using CodeIgniter and PHP, it aims to streamline the sales process and manage inventory efficiently.

## Features

- **Point of Sale:**
  - Quick and easy transaction processing
  - Real-time sales tracking
  - Customer management
- **Inventory Management:**
  - Stock monitoring and control
  - Automated low-stock alerts
  - Detailed product information and categorization
- **Reporting:**
  - Sales and inventory reports
  - Exportable data formats (CSV, PDF)
- **User Management:**
  - Role-based access control
  - Secure login and authentication
